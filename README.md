
# 💰 Module 4 - Expense Tracker App

A mobile Expense Tracker application built using React Native, Expo, and Firebase.

## 🚀 Features

- User Registration and Login
- Firebase Authentication
- Add New Expenses
- Edit and Delete Expenses
- Search Expenses
- Filter Expenses by Category
- Monthly Expense Report
- Category-wise Spending Summary
- Firebase Firestore Database
- Professional User Interface

## 🛠️ Technologies Used

- React Native
- Expo
- TypeScript
- Firebase Authentication
- Cloud Firestore
- AsyncStorage

## ⚙️ Installation

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder:

   ```bash
   cd Module03-Expense-Tracker
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the application:

   ```bash
   npx expo start
   ```

## 🔐 Security

Firebase Authentication and Firestore Security Rules are used to protect user expense data.
